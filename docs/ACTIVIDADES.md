# Actividades / mini-juegos

Acceso: Ajustes > Juegos.

## Aventura (D&D ligero)
- Estado: HP, inventario, lugar, turno (localStorage).
- El chat recibe un bloque de sistema con reglas de narrador.
- El usuario escribe acciones libres; el modelo ofrece opciones.

## Ajedrez narrado
- No es un motor fuerte: libro de aperturas debil + narracion del modelo.
- Jugadas: e2e4, Cf3, etc.

## Salir
Boton Terminar actividad en el panel.
